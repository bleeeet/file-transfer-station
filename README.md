# 文件中转站

为个人百度网盘中转文件的轻量 macOS 应用。Apple Silicon，macOS 13 或更新版本。原生 SwiftUI/AppKit，内置 BaiduPCS-Go v4.0.2；无需安装官方客户端。

## 使用

1. 打开应用，点「登录账户」，用百度网盘 App 扫窗口里的二维码并在手机上确认；也可改用百度网页登录或账号密码登录，需要验证码时在同一窗口填写。
2. 成功后默认打开百度网盘 `/文件中转站`；不存在时创建，已有时复用。可从顶部进入根目录或其他文件夹。
3. 把本地文件/文件夹拖进窗口，或点「选择文件上传」。所有上传均进入中转站，与当前浏览目录无关。
4. 上传直接进入 `/文件中转站`，不在网盘建临时文件夹；上传文件夹时先在网盘建好同样的文件夹结构（含空文件夹），因为 BaiduPCS-Go 遇到网盘上不存在的目标文件夹会整批失败；完成后核对文件都在才报告成功。失败或停止时会提示中转站里可能留有未传完的文件，并显示传输工具给出的失败原因。
5. 其他设备登录同一账号，右下角循环箭头刷新后即可查看。右键选择「下载到…」，或拖到 Finder 文件夹下载；同名目标不会覆盖。
6. 下载先写入目标目录的 `.中转站下载-<任务ID>`，通过任务结果和文件存在检查后才发布到目标位置。失败的临时文件保留。

登录凭据由 BaiduPCS-Go 保存在 `~/.config/BaiduPCS-Go`，目录权限 700、文件权限 600；不包含在应用及分发压缩包中，不写入应用日志。与已安装的命令行工具共享登录状态。扫码登录直接调用百度通行证接口，网页登录使用临时 WebKit 会话；两者都只在内存中持有会话，登录凭据仅经子进程输入导入，不经命令行参数传递。

应用关闭后停止子进程，不自启，不进行常驻同步。每台设备单独登录。首次拷到另一台电脑打开时，macOS 可能要求使用 Finder 右键「打开」确认；当前为本地签名，未做 Apple 公证。

## 验证与限制

本地测试覆盖目录数量核对、带空格/特殊字符名称、部分失败识别、自动目录、上传发布、下载内容核对、文件承诺下载回调、账号密码/验证码输入和凭据遮蔽。启动和登录 UI 已检查。真实百度账号、会员速度及 50 GB 大文件尚需实际登录传输验证；第三方接口兼容性由上游工具决定。

当前版本串行传输，一次一批；传输时底部显示进度条、已传/总量、速度和剩余时间（多个文件时为当前文件）；已有同名云端内容会停止并要求改名，不做自动覆盖或删除。

## 构建

在项目目录运行 `./build.sh`，产物为 `build/文件中转站.app`。不需要额外编程语言运行时，内置 CLI 资源保留其 Apache 2.0 许可证。

百度网盘 Logo 来自其官方 App Store 页面，仅用于本地个人工具的识别；该应用不属于百度官方客户端。

## 项目文件

源码在 `Sources/`，资源在 `Resources/`，测试在 `Tests/`，构建产物在 `build/`，分发压缩包在 `安装包/`。`/Applications/文件中转站.app` 是本机运行副本；账号配置保留在系统用户目录，不随项目或安装包分发。

扫码导入兼容修复：Cookie 末尾补分号，只取适用于 pan.baidu.com 的 Cookie，等待跳转网盘页；导入失败保留原因，认证命令不写入终端历史。

网页登录改为百度通行证登录页（tpl=netdisk）并使用 Safari 标识，避免网盘首页在内嵌浏览器中空白；登录后自动进入网盘页获取 STOKEN 再导入。

扫码登录改为原生实现：内嵌通行证页面在手机确认后不跳转、拿不到 BDUSS，现由应用直接请求二维码、轮询确认并换取网盘 STOKEN。
